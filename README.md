# Cassie ARL

**Thesis Project**: Robust Standing Control of a Bipedal Robot Using Adversarial Reinforcement Learning

This repository implements a complete, standalone Adversarial Reinforcement Learning (ARL) framework for training robust standing controllers for the bipedal robot Cassie. The ARL approach jointly trains Cassie against an adversarial agent that applies destabilising forces, resulting in policies that significantly outperform baseline reinforcement learning across recovery tasks and generalisation to varying physical parameters.

## Overview

Bipedal robots face fundamental challenges in achieving robust standing due to the simulation-to-reality gap. This thesis investigates ARL as a practical framework for learning robust bipedal control that generalises beyond its training distribution.
